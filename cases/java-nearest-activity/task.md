# Ближайшая запланированная активность

В `src/ActivityService.java` исправь `nearestPlanned`. Метод принимает активности, ID владельца и текущий момент времени, возвращает `Optional<Activity>`.

Требования:

- Учитывать только статус `PLANNED` указанного владельца.
- `scheduledAt` должен быть не раньше `now`; точное совпадение допустимо.
- Исключать записи с `null` вместо активности или времени.
- Выбирать минимальный `scheduledAt`, при равенстве — минимальный `id` по `String.compareTo`.
- При отсутствии подходящих записей или `null` вместо списка вернуть `Optional.empty()`.
- Не менять входной список. Он может быть неизменяемым.
- ID и ownerId непустых записей, аргументы ownerId/now гарантированно не null.

Сохрани публичный API. Новые зависимости не нужны. Можно добавить свои тесты. Java 17+; проверка компиляции: `javac -d build src/ActivityService.java`.

Это автономная учебная fixture, вдохновлённая типовой задачей из обзора рабочих проектов. Условия выше являются полным контрактом именно этой задачи.

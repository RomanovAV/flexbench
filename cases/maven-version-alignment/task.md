# Согласованное обновление зависимостей

Обнови вымышленные зависимости семейства `org.example.framework` с 3.2.0 до **3.2.1** во всех модулях. Источник версии должен быть один — свойство `framework.version` в корневом `pom.xml`.

Требования:

- Корневой dependencyManagement для `framework-core` и зависимость модуля `api` от `framework-http` должны разрешаться в 3.2.1 через `${framework.version}` (в том числе допустимо управление версией через dependencyManagement).
- Убрать старое локальное переопределение семейства в модуле; дочерний модуль не должен объявлять собственный `framework.version`.
- Сохранить parent-связь api → pilot-parent:1.0.0, root packaging=pom, модуль api, координаты обоих проектов и версию самих проектов 1.0.0.
- Сохранить dependencyManagement для framework-core и прямую зависимость api от framework-http. Не удалять зависимости ради прохождения проверки.
- Независимая зависимость api `org.example:utility` должна остаться compile-зависимостью версии 5.0.0, её версия не относится к обновляемому семейству.
- Оба POM должны оставаться корректными XML. Не добавляй плагины, репозитории или новые зависимости, кроме добавления framework-http в dependencyManagement при необходимости.

Это offline-fixture с вымышленными координатами и заданными версиями. Ничего скачивать не нужно. Проверка измеряет согласованность конфигурации, а не актуальность security-рекомендаций или совместимость настоящего Spring Boot.

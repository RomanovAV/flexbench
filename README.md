# FlexBench

Переиспользуемый бенчмарк типовых задач из рабочих репозиториев: сравнение GigaCode/GigaFlex и проверка изменений rules, системного промпта и моделей.

Сейчас подготовлены [инструкция создания бенчмарка](GIGAFLEX_BENCHMARK_INSTRUCTIONS.md) и скрипт первичной инвентаризации. Задачи, runner и адаптеры предстоит реализовать после изучения рабочих проектов.

## Начать на рабочей машине

Из корня `flexbench`, с Python 3.9+ и Git:

```bash
python3 scripts/inventory_repositories.py \
  --root ~/Development --root ~/IdeaProjects \
  --output artifacts/repository-inventory.json
```

Скрипт ищет Git-репозитории на глубине до трёх каталогов, включая Git worktrees. Не обходит симлинки и вложенные репозитории. Собирает revision, состояние рабочей копии, расширения отслеживаемых файлов, имена конфигураций и темы последних 20 коммитов. Не читает содержимое исходников, не запускает проектный код, не обращается к моделям или сети. Для отключения истории: `--commits 0`; для другой глубины: `--depth N`.

JSON содержит внутренние пути и темы изменений; храните его в рабочем контуре. `artifacts/` исключён из Git. Существующий отчёт не перезаписывается: для нового обзора укажите новый путь. Exit code `0` — обзор без обнаруженных ошибок; `2` — ошибки аргументов либо неполный/пустой обзор (при созданном отчёте см. `warnings` и `errors`). Наличие файлов конфигурации и расширений само по себе не устанавливает стек или архитектуру.

После инвентаризации передайте рабочему агенту:

> Выполни GIGAFLEX_BENCHMARK_INSTRUCTIONS.md: изучи проекты в ~/Development и ~/IdeaProjects и реализуй в flexbench бенчмарк типовых задач, адаптеры GigaCode/GigaFlex и сравнение профилей rules/промпта. Начни с 2–3 воспроизводимых задач и работающего сквозного запуска, затем расширь набор. Используй скрипты и независимые проверки результата.

Полный модельный прогон выполняется внутри корпорации после подготовки задач и настройки доступов. Подготовленная инструкция и инвентаризация ещё не являются работающим бенчмарком.

Проверить скрипт на временных Git-репозиториях:

```bash
python3 -m unittest discover -s tests -v
```
